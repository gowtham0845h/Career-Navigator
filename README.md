# Career Navigator

A responsive career planning app for students, built with React, TypeScript, Vite, Express, and Supabase. The role and job catalog is seeded from [`data/seed.json`](data/seed.json); profile and student progress are stored in Supabase.

## Supabase setup

1. Create a Supabase project and open its SQL Editor.
2. Run [`supabase/schema.sql`](supabase/schema.sql) to create the tables and row-level security policies.
3. In Supabase **Project Settings → API**, copy the project URL, anon key, and service role key. Keep the service role key on the server only.
4. In **Authentication → Providers**, enable Email. For the one-click demo button, also enable Anonymous Sign-Ins. Anonymous users receive their own private profile and journey.
5. Copy `.env.example` to `.env`, and fill in the four Supabase values. `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` are used by the browser; `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` are used by Express.

On API startup, roles and jobs from `data/seed.json` are upserted into Supabase. Job dates are relative to the startup date so the seeded catalog contains upcoming, open, closing-soon, and closed listings. Status is calculated from the date each time the API serves jobs.

## Run locally

```sh
npm install
npm run dev
```

Vite serves the frontend at `http://localhost:5173`; Express serves the API at `http://localhost:3001`. The Supabase schema and environment values are required for sign-in and persistent data.

## Production

```sh
npm run build
npm start
```

Deploy the Vite `dist/` output to a static host and the Express server to a Node host, or configure a reverse proxy to serve both. Set `VITE_API_URL` at frontend build time to the deployed API origin and set the Supabase environment variables on the API service. Set `CLIENT_ORIGIN` to the allowed frontend origin(s), comma-separated.

## Notes

- Mentor roadmaps are template-driven and generated by `server/mentor.ts`; `generateRoadmap` is the single provider seam for a future LLM integration.
- Job application links point to company career search pages. Listing details and dates are sample data, not live company feeds.
- The company interview notes are general guidance and are not official hiring policies.
- Saved jobs, checklist state, profiles, mentor preferences, chat messages, and roadmap completion are per-user rows protected by Supabase RLS and accessed through the authenticated API.
